## Aufrufen der Git Lab page
Da die GitLab page nicht mehr verlangt wird, ist hier die Projektvorstellung:
Dieser multi modal Browser ermöglicht die intuitive und interaktive Nutzung aller Bundestagsdebatten
der 20. Wahlperiode.

Neben der Visualisierung der Redentexte ist dabei auch eine vielzahl anderer Funktionalitäten
verfügbar.

→ Filterung nach verschiedensten Kriterien wie z.B. dem Namen, Datum, ID, etc..

→ Suche von Abgeordneten

→ Filterung der Reden eines Abgeordneten nach unterschiedlichen Kriterien

→ Visualisierung von NLP Analysen

→ Videostreaming der Reden

→ Exports der Reden
